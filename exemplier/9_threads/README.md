# Threads in Concurrent Programming

This section contains examples related to the use of threads for concurrent programming in C. Below is a list of the source files with links to their content.

| File Name                         | Description | Link |
|-----------------------------------|-------------|------|
| `test_pthread.c`                  | Creates and joins 50 000 threads one after the other and measures the elapsed time with `clock_gettime()`; compare with `test_fork.c` | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/test_pthread.c) |
| `test_fork.c`                     | Same measure with processes: creates and waits for many children with `fork()` / `waitpid()`, to compare the cost of a process with that of a thread (`test_pthread.c`) | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/test_fork.c) |
| `knowing_nbcores.c`               | Queries the number of online CPUs using `sysconf(_SC_NPROCESSORS_ONLN)` | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/knowing_nbcores.c) |
| `thread_01.c`                     | Thread A writes a global variable while thread B reads it, without synchronization (deliberate race) | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_01.c) |
| `thread_02.c`                     | Three threads printing letters: main creates A and B, B creates C and waits for it with `pthread_join()`; the output of the threads interleaves | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_02.c) |
| `thread_02_withmutex.c`           | Same as `thread_02.c` but each block of letters is printed under a `pthread_mutex_t`, so blocks no longer interleave | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_02_withmutex.c) |
| `thread_with_shm_without_mutex.c` | 4 producers and 1 consumer access a global variable (shared by the threads) without mutex: data race | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_with_shm_without_mutex.c) |
| `thread_with_shm_and_mutex.c`     | 4 producers and 1 consumer share a variable protected by a mutex (active polling); the consumer stops when the producers are finished | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_with_shm_and_mutex.c) |
| `thread_with_conditions.c`        | Three threads increment a counter; when it reaches a limit, one of them wakes a watching thread with `pthread_cond_signal()`, which waits with `pthread_cond_wait()` (adapted from LLNL) | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_with_conditions.c) |
| `thread_with_signal.c`            | Signal and threads: `main()` sends SIGINT to a thread with `pthread_kill()`; the async-signal-safe handler sets a flag that stops it | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_with_signal.c) |
| `pb_reentrant.c`                  | Shows the problem of a non-reentrant function with a hidden `static` state (like `rand()`) called from multiple threads | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/pb_reentrant.c) |
| `without_pb_reentrant.c`          | Fix for `pb_reentrant.c`: reentrant version where the caller provides the state (like `rand_r()`) | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/without_pb_reentrant.c) |
| `pthread_barrier.c`               | Custom implementation of `pthread_barrier_t` for macOS, which does not provide it natively | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/pthread_barrier.c) |
| `barrier.c`                       | Demonstrates `pthread_barrier_wait()`: all threads block until the last one arrives | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/barrier.c) |
| `timer_and_citizens.c`            | A timer thread wakes up citizen threads with `pthread_cond_broadcast()` (predicate + `while` loop) | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/timer_and_citizens.c) |
| `thread_hello.c` | First Pthread program: creates a thread, displays both identifiers with `pthread_self()`, then joins it (course, chapter « Threads ») | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_hello.c) |
| `thread_square.c` | Passes an argument to a thread and gets its result (allocated on the heap) back with `pthread_join()` (course, chapter « Threads ») | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_square.c) |
| `thread_detached.c` | Creates a detached thread with `PTHREAD_CREATE_DETACHED`; `main()` ends with `pthread_exit()` (course, chapter « Threads ») | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_detached.c) |
| `matrix_product_threads.c` | Running example: square matrix product computed by 4 threads, one per quadrant of the result, compared with the single-thread version (course, chapter « Threads ») | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/matrix_product_threads.c) |
| `thread_shared_variables.c` | Program to analyse: which variables (global, `static`, local, via pointer) are shared by the threads (course, chapter « Threads ») | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_shared_variables.c) |
| `thread_arg_pitfall.c` | Pitfall of passing `&i` of a loop to several threads, followed by the correction (one argument per thread) (course, chapter « Threads ») | [View](https://github.com/alainlebret/os/blob/master/exemplier/9_threads/src/thread_arg_pitfall.c) |
