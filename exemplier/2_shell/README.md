# Bash Script Examples

This section contains examples of Bash scripting in Unix-like systems. These scripts cover various aspects of shell scripting, including basic commands, variable usage, control structures, and more. Below is a list of the Bash script files with descriptions and links to their content.

| File Name             | Description                                                               | Link |
|-----------------------|---------------------------------------------------------------------------|------|
| `1_hello.sh`            | Demonstrates the use of the `echo` command with different string delimiters | [1_hello.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/1_hello.sh) |
| `2_clean.sh`            | Removes the backup files (`*~`) of the current directory with `rm -f -- ./*~`         | [2_clean.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/2_clean.sh) |
| `3_variables_01.sh`     | Demonstrates variables and their contents using `echo`                      | [3_variables_01.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/3_variables_01.sh) |
| `3_variables_02.sh`     | Illustrates the difference between simple and double quotes (expansion of `$BAD` or not)               | [3_variables_02.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/3_variables_02.sh) |
| `4_read.sh`             | Reads a file name with `read -r`, checks that it exists, then removes it with `rm -i`                                                 | [4_read.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/4_read.sh) |
| `5_substitution_01.sh`  | Shows command substitution (example 1)                                    | [5_substitution_01.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/5_substitution_01.sh) |
| `5_substitution_02.sh`  | Command substitution to know whether backup files exist on the desktop, then `find -exec rm -i` to remove them one by one                                    | [5_substitution_02.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/5_substitution_02.sh) |
| `5_substitution_03.sh`  | Command substitution in a file name: `backup-$(date …).tar.gz` archive of the directory given as parameter (`5_substitution_03.sh DIRECTORY`)                                    | [5_substitution_03.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/5_substitution_03.sh) |
| `6_arithmetic_01.sh`    | Illustrates arithmetic operations in Bash                                 | [6_arithmetic_01.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/6_arithmetic_01.sh) |

| `7_exp02_number_1.sh`   | Tests an expression with nested `if` statements (`[ … -lt … ]`), after checking that the input is an integer                                               | [7_exp02_number_1.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/7_exp02_number_1.sh) |
| `7_exp02_number_2.sh`   | Same test with `[[ … && … ]]`                                               | [7_exp02_number_2.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/7_exp02_number_2.sh) |
| `7_exp02_number_3.sh`   | Same test with the arithmetic command `(( x > 1 && x < 10 ))`                                               | [7_exp02_number_3.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/7_exp02_number_3.sh) |
| `7_exp02_number_4.sh`   | Same test with two `[ ]` joined by `&&`                                               | [7_exp02_number_4.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/7_exp02_number_4.sh) |

| `10_for_01.sh`          | Demonstrates iteration using `for` loop                                   | [10_for_01.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/10_for_01.sh) |
| `10_for_02.sh`          | Demonstrates iteration using `for` loop                                   | [10_for_02.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/10_for_02.sh) |
| `10_for_03.sh`          | Loops over the files of the current directory: name, extension (`${file%%.*}`, `${file##*.}`) and count                                   | [10_for_03.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/10_for_03.sh) |

| `11_while_menu.sh`      | Shows a menu using `while` loop                                           | [11_while_menu.sh](https://github.com/alainlebret/os/blob/master/exemplier/2_shell/11_while_menu.sh) |
